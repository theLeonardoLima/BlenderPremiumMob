# Adendo bug-BUG-20261006-KFAR-v001 · Arquivos .blend do pacote e build (spec-gap)

- **Bug:** BUG-20261006-KFAR (erro ao aplicar o editor de paredes / construtor no Windows: `GeoNodeWall.blend failed to open`)
- **Tipo:** aditivo (spec-gap: o versionamento e o empacotamento dos arquivos do pacote não estavam especificados)
- **Vigência:** a partir de 2026-10-07
- **Aprovação:** Leonardo Lima, 2026-10-07 (veredito `spec-gap` no `/reversa-debugger-fix`)
- **Imutável:** mudanças futuras viram um novo adendo (`-v002`)

## Especificação

1. Os arquivos `.blend` do pacote (`caffmob_draw/**/*.blend`: nós de Geometry Nodes, modificadores de peça,
   puxadores, perfis, molduras, materiais) fazem parte do código-fonte e **são versionados** no git. Os `.blend` de
   projeto do usuário continuam fora do git.
2. Um plugin gerado a partir de um clone do repositório (`git clone` + `python build.py`) é completo: cria paredes,
   módulos e frentes sem depender de arquivos fora do git.
3. O `build.py` confere, antes de empacotar, os `.blend` de nós usados no código (`GeoNode*` em
   `geometry_nodes/`, `CPM_*` em `geometry_nodes/CabinetPartModifiers/`); se faltar algum, lista os arquivos e termina
   com erro, sem gerar o zip.

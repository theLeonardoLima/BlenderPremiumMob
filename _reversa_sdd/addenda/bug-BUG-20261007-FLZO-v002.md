## Especificação

1. Quando o texto não pode mudar no código e colide com uma palavra genérica do Blender (ex.: o nome de um item do
   catálogo de produtos também é o id dele, "Range"), a entrada do catálogo leva `"contexto": "<nome>"` e é registrada
   só nesse contexto. Quem desenha passa o mesmo contexto: `layout.label(text=..., text_ctxt=...)`,
   `layout.operator(..., text_ctxt=...)` ou `tr(texto, contexto)`.
2. Nomes e descrições do catálogo de produtos usam o contexto `caffmob_catalogo` (`catalog/catalog_data.py`
   `TEXT_CTXT`).
3. Mensagens montadas em listas que depois são juntadas (`" | ".join(...)`) ou comparadas são traduzidas na criação
   (`tr()`), nunca só marcadas (`N_()`); código não decide nada pelo texto de uma mensagem (prefixos comparados usam o
   texto já traduzido).
4. Os testes de fumaça no Blender rodam com a interface em pt_BR e sem traduzir nomes de dados novos
   (`tests/_blender_env.py`); o idioma é testado em `tests/blender_bug_FLZO_i18n.py`.
